# X5 Retail Analysis

**[Открыть полное исследование в Jupyter Notebook](x5_retail_analysis.ipynb)**

**Чем различались темпы роста сетей X5 в 2025 году и какие показатели сопровождали эту динамику?** Сравниваем масштаб сетей, LFL-продажи, трафик, средний чек и расширение, чтобы определить вопросы для управления бизнесом.

## Данные

Источник — [публичная отчётность X5](https://www.x5.ru/en/investors/financial-and-operational-results/), Excel *Financial and Operating Results (RUB)*, лист `Operating Results`. Годовые периоды: «2024 Скорр.» и «2025 (2)».

[`data/x5_operating_results.csv`](data/x5_operating_results.csv) — подготовленная аналитическая выборка из публичной отчётности X5. Четыре столбца: раздел, показатель, период и значение. Выручка указана в млн руб., площадь — в тыс. кв. м, магазины — в штуках. Процентные показатели хранятся как доли; при выводе LFL notebook умножает их на 100. Репозиторий воспроизводит анализ CSV; полный процесс подготовки исходного Excel в него не входит.

## Основные выводы

- **Пятёрочка:** 79,2% выручки трёх сетей; наибольший абсолютный прирост — 499 437 млн руб. (+16,0%).
- **Перекрёсток:** выручка выросла на 8,2% при почти стабильной сети; LFL-трафик снизился на 2,2%.
- **Чижик:** самый высокий рост выручки (+67,3%), LFL-продаж (+26,1%) и числа магазинов (+38,7%).

## Рекомендации бизнесу

Сопоставить рентабельность новых и действующих магазинов Пятёрочки, изучить снижение трафика Перекрёстка и проверить экономику новых точек Чижика.

Агрегированные данные трёх сетей за два года позволяют сопоставить показатели, но не доказать причины роста или выделить точный вклад LFL и расширения. Доли относятся только к этим сетям; данных о прибыли, ценах и сроках открытия магазинов нет.

## Как запустить в Windows

Установите Python 3.12 с Python Launcher. Откройте PowerShell в папке проекта и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install pandas matplotlib notebook
.\.venv\Scripts\jupyter.exe notebook x5_retail_analysis.ipynb
```

В открывшемся notebook выполните **Run → Run All Cells**. Таблицы и все три графика сохранены внутри notebook для чтения на GitHub.
