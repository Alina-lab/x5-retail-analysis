# X5 Retail Analysis

**[Открыть полное исследование в Jupyter Notebook](x5_retail_analysis.ipynb)**

Почему динамика выручки Пятёрочки, Перекрёстка и Чижика в 2025 году различалась? Сравниваем масштаб сетей, LFL-продажи, трафик, средний чек и расширение.

## Данные

Источник — [публичная отчётность X5](https://www.x5.ru/en/investors/financial-and-operational-results/), Excel *Financial and Operating Results (RUB)*, лист `Operating Results`. Годовые периоды: «2024 Скорр.» и «2025 (2)».

Анализ использует подготовленный `data/processed/x5_operating_results_long.csv`, полученный из этой отчётности. Репозиторий воспроизводит расчёты по CSV; полный процесс подготовки исходного Excel в него не входит. Выручка указана в млн руб., площадь — в тыс. кв. м.

## Основные выводы

- **Пятёрочка:** 79,2% выручки трёх сетей; наибольший абсолютный прирост — 499 437 млн руб. (+16,0%).
- **Перекрёсток:** выручка выросла на 8,2% при почти стабильной сети; LFL-трафик снизился на 2,2%.
- **Чижик:** самый высокий рост выручки (+67,3%), LFL-продаж (+26,1%) и числа магазинов (+38,7%).

## Рекомендации бизнесу

Сопоставить рентабельность новых и действующих магазинов Пятёрочки, изучить снижение трафика Перекрёстка и проверить экономику новых точек Чижика.

## Как запустить

Нужен Python 3.12. Из корня проекта:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook x5_retail_analysis.ipynb
```

В открывшемся notebook выполните **Run → Run All Cells**. Таблицы и графики уже сохранены и доступны для чтения на GitHub. Инструменты: pandas, Matplotlib и Jupyter Notebook.

## Ограничения

Рассмотрены агрегированные данные трёх сетей за два года. Доли относятся только к этим сетям. Нет данных о прибыли, ценах и сроках открытия магазинов. Связь показателей не доказывает причинность; точный вклад LFL и расширения в рост выручки определить нельзя.
