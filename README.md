# X5 Retail Analysis

**[Открыть полное исследование в Jupyter Notebook](x5_retail_analysis.ipynb)**

Чем различались темпы роста сетей X5 в 2025 году и какие показатели сопровождали эту динамику? Сравниваем масштаб сетей, LFL-продажи, трафик, средний чек и расширение, чтобы определить вопросы для управления бизнесом.

## Данные

Источник — [публичная отчётность X5](https://www.x5.ru/en/investors/financial-and-operational-results/).

[`data/x5_operating_results.csv`](data/x5_operating_results.csv) — подготовленная аналитическая выборка из публичной отчётности X5.

## Основные выводы

- **Пятёрочка:** 79,2% выручки трёх сетей; наибольший абсолютный прирост — 499 437 млн руб. (+16,0%).
- **Перекрёсток:** выручка выросла на 8,2% при почти стабильной сети; LFL-трафик снизился на 2,2%.
- **Чижик:** самый высокий рост выручки (+67,3%), LFL-продаж (+26,1%) и числа магазинов (+38,7%).

## Выводы и рекомендации

Сопоставить рентабельность новых и действующих магазинов Пятёрочки, изучить снижение трафика Перекрёстка и проверить экономику новых точек Чижика.

Агрегированные данные трёх сетей за два года позволяют сопоставить показатели, но не доказать причины роста или выделить точный вклад LFL и расширения. Доли относятся только к этим сетям; данных о прибыли, ценах и сроках открытия магазинов нет.
